# TASK 16164 — literal brief (follow it exactly; do not re-explore)

Issue: https://github.com/tangency-labs/solidcraft/issues/16164

## What the user did and what happened

The user selected ONE sketch point (`p8`) and moved it 6 mm with the Move/Copy tool.
The operation was refused and the UI showed:

    "Sposta/Copia entità dello schizzo: fixed or projected geometry cannot move"

The command that failed (from the issue body):

    sketch.move  { "entities": ["p8"], "translate": [6.0, 0.0], "angle": 0.0, "copy": false }

The design had 10 features and 2 bodies. The messages in the log show the user had
just drawn a rectangle by its centre and a circle by its centre.

## Where the refusal comes from — READ THIS, IT IS THE WHOLE TASK

File: `crates/engine/src/cmd/sketch_modify.rs`

* line 3561: `fn transform_in_place(sk: &mut Sketch, cs: &[usize], ps: &[usize], f: &dyn Fn(Vec2) -> Vec2, k: f64, cmd: &str) -> Result<()>`
* line 3563-3565:

      if pts.iter().any(|q| sk.points.get(*q).is_some_and(|x| x.fixed || x.link.is_some())) {
          return Err(bad(cmd, "fixed or projected geometry cannot move"));
      }

* line 3397: `fn involved_points(sk: &Sketch, cs: &[usize], ps: &[usize]) -> Vec<usize>`
  collects, for the selected curves, EVERY point of the curve (`k.point_ids()`), plus
  the selected points.
* `sketch.move` calls `transform_in_place` at line 3734 (`sketch.transform` at 3765
  and 3838).

So: the move is refused when ANY point that the operation would drag is `fixed`
(the sketch origin is fixed — `crates/sketch/src/model.rs:804` creates the origin
point with `fixed: true` — and a point held by an expression is fixed too,
`crates/engine/src/cmd/sketch.rs:1396`) or is `link`ed (projected from another
sketch or body).
